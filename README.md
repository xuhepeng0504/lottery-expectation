# 号码期望值实验室

抓取**双色球 / 超级大乐透**近三个月官方开奖数据，做统计分析与「期望值」评分，生成一个**每次打开都会自动联网更新**的每日查看网页。

> ⚠️ 重要说明：彩票每期开奖都是独立随机事件，任何模型都无法预测号码。本工具中的「期望值」是号码的统计评分，**不是中奖概率，也不构成中奖承诺**，仅供数据统计与娱乐参考。请理性购彩、量力而行，未满 18 周岁禁止购彩。

## 永久固定网址（电脑关机也能看）

支持部署到 **GitHub Pages**：云端每 15 分钟自动抓取开奖 → 重新计算 → 发布页面，**网址永久固定，电脑关机/断网也能访问**。

- 详细步骤见 **[部署到GitHub-永久网址.md](部署到GitHub-永久网址.md)**（网页手动约 5 分钟）
- 或右键运行 **`发布到GitHub.ps1`** 一键创建仓库并部署（需要一个 GitHub Token）
- 部署后固定网址：`https://<用户名>.github.io/<仓库名>/`

> 本地联网服务（`查看网页.bat`）、局域网手机访问、Cloudflare 临时公网链接仍可继续使用；GitHub Pages 只是多一个「永久、免开机」的入口。

## 打开网页（推荐）

双击 **`查看网页.bat`** → 自动启动本地服务并打开：

```
http://127.0.0.1:8765/
```

- **每次进入/刷新页面，都会自动联网抓取官方最新开奖数据并重新计算、重渲染**（约 9 秒）。
- 页面顶部状态会显示：`正在联网更新…` → `已联网更新` / `数据已是最新` / `联网失败 · 显示缓存`。
- 若刚更新完 5 秒内再次进入，直接使用缓存（不重复抓取）。
- 服务监听 `0.0.0.0:8765`，**同一 Wi-Fi 下的手机/平板也能访问**（路由器未做端口映射，不会暴露到公网）；详见下文「手机 / 微信访问」。
- 页面也支持从**其他本地来源**打开（例如聊天窗口里的文件预览）：只要本机服务在运行，页面会自动跨域请求 `127.0.0.1:8765`（服务端已开启 CORS）。但最稳妥的方式仍然是双击 `查看网页.bat`。
- 联网失败时页面会自动重试 3 次；也可以**点击右上角状态**立即强制重试。

### 自动启动

已注册两个计划任务：

- **`彩票期望值-网页服务`**：每次登录 Windows 时自动在后台启动本地服务（无窗口）。
- **`彩票期望值-公网隧道`**：每次登录时自动启动 Cloudflare 公网隧道（无窗口），把本地页面映射成公网 HTTPS 链接。

所以绝大多数情况下，双击 `查看网页.bat` 会瞬间打开页面；双击 `分享链接.bat` 会直接拿到当前公网链接。

### 离线兜底

`index.html` 是自带数据的单文件页面，双击也能看（数据为最后一次更新的快照），此时页面顶部会提示「本地离线数据」。**联网自动更新请使用 `查看网页.bat`。**

## 公网分享（其他人也能看）

> 无需服务器、无需账号、无需路由器端口映射，用 Cloudflare 免费隧道把本机页面映射成公网 HTTPS 链接。手机、电脑、任意网络都能打开。

**操作**：双击 **`分享链接.bat`** → 自动启动隧道、把公网地址复制到剪贴板并打开浏览器 → 直接粘贴到微信/QQ 发给别人即可。

- 页面底部「公网分享」也会显示当前链接。
- 打开页面即自动联网更新；页面保持打开时每 **10 分钟**静默刷新一次（有新开奖才重渲染，不打断阅读）。
- **链接有效期**：Cloudflare 快速隧道是免账号的临时域名，**电脑重启或隧道重启后链接会变化**，重新双击 `分享链接.bat` 获取新链接即可（页面底部同步更新）。
- **电脑需要保持开机且联网**；电脑关机/断网后链接不可用。
- 安全性：链接是随机域名，拿到链接的人都能访问；页面只包含公开彩票数据，不含个人信息。请不要在页面里放隐私内容。

> 如果需要**固定域名**（重启不变）或**电脑关机也能访问**，需要 Cloudflare 账号 + 域名（免费套餐即可）或一台云服务器，可再单独配置。

## 手机 / 微信访问

> 页面服务通过局域网提供，手机和电脑连同一个 Wi-Fi 即可，不需要公网、不用上传任何文件。

1. **电脑和手机连接同一个 Wi-Fi**（不能是访客网络；路由器如果开了「AP 隔离」，设备之间无法互访）。
2. 双击 **`开启手机访问.bat`**，在弹出的 UAC 窗口点「是」（只需一次，放行 TCP 8765 端口）。Windows 防火墙默认会拦截外部设备访问，这步是必须的。
3. 确认电脑上服务在运行：双击 `查看网页.bat`（或看任务计划里 `彩票期望值-网页服务` 是否在运行）。
4. 在**手机浏览器**打开：`http://192.168.31.8:8765/`（换成电脑页面底部「手机访问」显示的地址；IP 可能变化，以页面显示或 `data/access_url.txt` 为准）。

微信里怎么打开：

- 把上面的地址发给「文件传输助手」，在手机上点开即可（微信内置浏览器）。
- 如果微信提示「网页无法访问」：点右上角「···」→ **在浏览器打开**；仍不行就是防火墙未放行或不在同一 Wi-Fi。
- 注意：**不要把 `index.html` 文件当附件发到微信**，微信不支持直接打开 HTML 文件；要发的是上面的网址。
- 如果电脑换了 Wi-Fi / 路由器重启，IP 可能变，打开电脑页面看底部最新地址即可。

> 安全提示：服务会监听局域网 8765 端口，建议只在自家/可信 Wi-Fi 使用；在公共 Wi-Fi 上可关闭规则：
> `netsh advfirewall firewall delete rule name="彩票期望值-手机访问"`（管理员 PowerShell）。

## 更新机制

| 场景 | 行为 |
| --- | --- |
| 每次打开页面 | 页面请求 `/api/data?refresh=1` → 服务端调用 `scripts/update.py`：抓取官方接口 → 分析选号 → 重建 `index.html` → 返回最新 JSON → 页面重渲染 |
| 5 秒内重复进入 | 直接返回缓存，避免重复抓取 |
| 服务启动时 | 后台预热一次，保证第一次打开就是较新数据 |
| 每天 09:05 | 计划任务 **`彩票期望值-每日更新`** 兜底更新一次（即使当天没开页面） |
| 手动更新 | 双击 `更新数据.bat`（完成后自动打开联网版页面） |

端口被占用时可换端口启动：`set LOTTERY_PORT=8766` 后再运行 `python scripts\server.py`（同时需修改 `查看网页.bat` 中的端口）。

## 模型说明

### 号码得分

| 因子 | 权重 | 含义 |
| --- | --- | --- |
| 近期热度 | 45% | 按 `0.90^期龄` 加权后的出现次数 ÷ 理论期望次数，再做 z-score |
| 遗漏回补 | 35% | 距离上次开出已过的期数，做 z-score（遗漏越深分越高） |
| 重号/邻号 | 20% | 与上一期开奖号码相同（重号）或 ±1（邻号）加权 |

### 组合评分

```
组合得分 = 号码平均得分 × 0.9 − 0.6 × 结构偏离惩罚
```

结构偏离惩罚会压低：和值远离近 3 月均值、奇偶失衡、三区（1–11/12–22/23–33）有空区、跨度异常、连号超过 1 组、AC 值过低。

最终映射为 **期望指数 = 50 + 22 × 组合得分**，**50 分 = 随机组合的平均水平**（页面同时显示当日随机基准分，通常约 40）。得分越高代表「越符合近期统计特征」，不代表更容易中奖。

选出的 5 组号码还要求：两两之间红球重叠 ≤ 2 个、和值各不相同，避免五组高度雷同。

### 理论期望回报

页面按最新一期实际奖金估算「每注 2 元的期望回报」：

- 双色球：约 `¥1.10 / 注`（返奖率约 55%），一等奖概率 1 / 17,721,088
- 大乐透：约 `¥1.07 / 注`（返奖率约 54%），一等奖概率 1 / 21,425,712

期望 = Σ(各奖级中奖概率 × 单注奖金)。长期看，**任何号码组合的期望回报都相同且低于 2 元**。

### 历史回测

每次更新会用截至某期之前的数据重新选号，再与当期真实开奖对比：

- 双色球：每组平均命中约 1.2 个红球，随机期望 1.09 个
- 大乐透：每组平均命中约 0.7 个前区号，随机期望 0.71 个

结果与随机基本一致 —— **统计模型无法提高中奖概率**，页面如实展示该结果。

## 常见问题

**Q：双击 `查看网页.bat` 后浏览器没打开？**
A：先手动访问 <http://127.0.0.1:8765/>；仍不行则说明服务未启动，查看 `logs/server.log`。也可直接双击 `index.html` 看离线快照。

**Q：页面显示「联网失败」？**
A：说明页面没有连上本地服务。① 确认双击过 `查看网页.bat`（或计划任务 `彩票期望值-网页服务` 正在运行）；② 点击右上角「联网失败」状态可立即重试，页面也会自动重试 3 次；③ 仍失败请查看 `logs/server.log`；④ 如果是从聊天里的文件卡片/预览窗口打开的，请改用 `查看网页.bat` 或直接访问 <http://127.0.0.1:8765/>。

**Q：页面显示「本地文件 · 未联网」？**
A：说明当前是用 `file://` 直接打开的 `index.html` 快照，浏览器不允许它访问本地服务。请双击 `查看网页.bat` 用联网版打开。

**Q：公网链接打不开 / 失效了？**
A：电脑关机、断网或隧道重启都会让旧链接失效（免账号的临时域名）。双击 `分享链接.bat` 获取新链接；确认计划任务 `彩票期望值-公网隧道` 在运行，日志见 `logs/tunnel.log`。

**Q：手机 / 微信打不开（显示“网页无法访问”）？**
A：三步检查：① 手机和电脑是否连**同一个 Wi-Fi**（访客网络/AP 隔离不行）；② 是否双击运行过 `开启手机访问.bat` 并在 UAC 点“是”（防火墙未放行是常见原因）；③ 电脑上的服务是否在运行。微信里可点「···→在浏览器打开」再试。仍不行时，用电脑访问 `http://127.0.0.1:8765/` 确认服务正常，并在手机浏览器里试同一地址。

**Q：为什么不能把 index.html 发到微信里打开？**
A：微信不支持直接渲染 HTML 附件（会变成下载/无法打开）。正确做法是把 **`http://电脑IP:8765/` 这个网址**发到微信，且手机与电脑在同一 Wi-Fi。

**Q：怎么停止后台服务？**
A：任务管理器结束 `pythonw.exe`，或 PowerShell 执行：
`Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*server.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }`

**Q：怎么关闭/修改定时任务？**
A：任务计划程序里有两个任务：`彩票期望值-每日更新`（09:05 数据兜底）、`彩票期望值-网页服务`（登录自启）。删除示例：
`schtasks /Delete /TN "彩票期望值-每日更新" /F`

**Q：换一台电脑还能用吗？**
A：可以。复制整个文件夹、安装 Python 3.8+ 后双击 `查看网页.bat`；计划任务按上文用 PowerShell 重新注册即可。

**Q：为什么 5 组号码有重复数字？**
A：5 组是独立候选组合，允许少量重叠（每两组红球最多重叠 2 个）；热号/遗漏号本来就会在多组中反复出现。
